数据流向一览

你放入 docs/ 的文件  →  ingest.py 扫描  →  解析器提取文本
                                              ↓
  CLI / Web 问答     ←  LLM 生成回答    ←  向量检索 (ChromaDB)  ←  Embedding 向量化

核心原则：docs/ 就是数据源。你往里面放什么格式的文件，系统就索引什么。

方式一：克隆 React 官方文档 .md

为什么是 React 文档？

React 官方文档站本身就是用 Markdown 写的，开源在 GitHub。克隆下来直接就是几千个高质量 .md 文件，不需要任何处理。

操作步骤

  1. 打开 VS Code 终端（Ctrl + `）
  2. 进入目标目录： 
    cd docs/react-docs
  3. 克隆仓库（浅克隆，只取最新版本，约 50MB）： 
    git clone --depth 1 https://github.com/reactjs/react.dev.git .

    注意末尾有个 .，表示克隆到当前目录而不是新建子目录。

如果没装 Git：
去 git-scm.com/download/win 下载安装，一路默认即可。
或者直接在 GitHub 页面点 "Code → Download ZIP"，解压到 docs/react-docs/。

克隆后检查

dir src\content\learn

这里面全是 .md 文件（如 your-first-component.md），就是 React 官方教程。

预期收获：约 200+ 个 Markdown 文件，覆盖 React 全部核心概念、API 参考、教程。这是你知识库的主力军。

方式二：PDF 电子书 / 论文 .pdf

从哪找？

来源内容怎么获取
ArXiv 学术论文（如 "Attention Is All You Need"） arxiv.org 搜索 → Download PDF
官方文档 PDF 版 React/Vue/Node.js 文档 很多文档站提供 PDF 下载（页脚找 "Download PDF"）
技术书籍 你自己购买的 PDF 电子书 放到 docs/ebooks/ 即可
公开手册 如 《TypeScript Handbook》PDF 搜索 "typescript handbook pdf"

放入方式

直接把 .pdf 文件拖进 docs/ebooks/ 文件夹，支持子目录。

docs/ebooks/
├── react-design-patterns.pdf
├── typescript-handbook.pdf
└── paper/
    └── attention-is-all-you-need.pdf

方式三：个人笔记 .md .txt

把你平时的学习笔记、代码片段、踩坑记录放进去。任何 .md 或 .txt 文件都可以。

快速生成测试笔记

在 VS Code 里直接新建文件，放到 docs/my-notes/：

docs/my-notes/
├── react-learning.md      # 已有（React 笔记示例）
├── python-tips.txt        # 已有（Python 虚拟环境笔记）
├── git-cheatsheet.md      # 你可以新建：Git 常用命令
├── css-布局笔记.md         # 你可以新建：Flexbox/Grid 笔记
└── js-闭包理解.txt         # 你可以新建：JS 闭包和原型链
格式要求：UTF-8 编码即可，Markdown 支持标题层级（# ## ###）。文件名中文英文都行。

方式四：网页存档 .html

怎么获取？

  1. 浏览器打开你想保存的技术文章
  2. Ctrl + S → 保存类型选 "网页，仅 HTML"
  3. 把 .html 文件放到 docs/web-archive/

适合保存什么？

  • 掘金 / 知乎 / Medium 上的高质量技术文章
  • 技术博客（如 Dan Abramov 的 overreacted.io）
  • 官方文档的某个单页（如 React 某个 API 页面）

方式五：Word 文档 .docx

把你工作中的技术文档、PRD、会议纪要（.docx 格式）放到 docs/ 下任意位置即可。

支持 Heading 样式识别，Word 里的"标题1/2/3"会被当作章节切分点。

放入数据后：三步验证

第 1 步：看文件认不认

python -c "
from src.ingest import IngestPipeline
p = IngestPipeline()
files = p._collect_files()
print(f'共发现 {len(files)} 个文件:')
for f in files:
    print(f'  {f.suffix}  {f.relative_to(p.docs_dir)}')
"

第 2 步：跑索引

python -c "from src.ingest import IngestPipeline; IngestPipeline().run()"

每行输出一个文件的索引结果，最后显示总数。首次跑 Embedding 模型会自动下载（约 2GB，只下载一次）。

第 3 步：搜一下试试

python -c "
from src.retrieve import Retriever
from src.generate import Generator
r = Retriever()
g = Generator()
hits = r.search('React 组件是什么')
print(f'找到 {len(hits)} 条结果')
ctx = r.format_context(hits)
print(g.generate('React 组件是什么', ctx))
"
看到什么算成功？DeepSeek 返回一段中文回答，引用你放进 docs/ 的文档内容，末尾带来源编号 [1]、[2]。

速查：各格式放哪里

格式放哪里获取方式
.mddocs/react-docs/ 或 docs/my-notes/git clone / 自己写
.pdfdocs/ebooks/下载 / 购买
.txtdocs/my-notes/自己写
.htmldocs/web-archive/浏览器 Ctrl+S 保存
.docxdocs/ 下任意位置工作文档复制过来

所有格式都支持子目录递归扫描，你可以在 docs/ 下随便建文件夹组织。
