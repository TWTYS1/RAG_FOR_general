第 1 步：确认 Python 环境

这个东西是干什么的？

Python 是这个项目的运行基础——就像一个"翻译官"，负责理解和执行我们写的代码。所以电脑里必须先有它。

检查有没有装

打开 VS Code 终端：菜单栏 → Terminal → New Terminal，或者直接按 Ctrl + `（Tab 上面那个键），然后输入：

python --version
期望看到：Python 3.10.x 或更高版本（3.11、3.12 都可以）
如果显示 "python 不是内部或外部命令"：
说明 Python 没装或没加到 PATH。去 python.org/downloads 下载，安装时一定勾选底部的 "Add Python to PATH"，然后再装。

同时确认 pip（Python 的包管理器，用来下载第三方库）可用：

pip --version

会输出类似 pip 24.x from ... 的信息。

第 2 步：创建虚拟环境 rag-env

这个东西是干什么的？

虚拟环境就像给这个项目建了一个独立的"小房间"。所有下载的包都锁在这个房间里，不会跟电脑上其他 Python 项目互相干扰。以后不想要了，删掉这个文件夹就彻底干净。

至于名字——rag-env = RAG + Environment，一眼就知道是这个项目专属的环境。

创建（只需做一次）

确保终端当前在项目目录：

cd D:\vibecoding\project1

然后执行：

python -m venv rag-env
这条命令做了什么？
在项目文件夹里生成了一个 rag-env\ 目录，里面装着一套独立的 Python 解释器 + pip。此时什么都没装，是个空房间。

执行完确认一下文件夹存在：

dir rag-env

应该看到 Scripts、Lib 等子目录，说明创建成功。

✅ 第 2 步完成。这个步骤只需要做一次，以后再次打开项目不需要重新创建。

第 3 步：激活环境 + 安装依赖包

3.1 激活虚拟环境

每次重新打开终端都要先激活，否则 pip 会把包装到系统 Python 而不是 rag-env 里。

rag-env\Scripts\activate

执行成功后，终端最前面会出现 (rag-env) 标记，像这样：(rag-env) D:\vibecoding\project1>

看到这个标记 = 你在小房间里了 = 可以安全安装。

3.2 安装 11 个依赖包

直接复制下面一整条命令，回车：

pip install chromadb openai tiktoken markdown-it-py pdfplumber python-docx beautifulsoup4 lxml python-dotenv streamlit sentence-transformers
下载要多久？首次安装大约 2–5 分钟（取决于网速）。会看到进度条在走，最后出现 Successfully installed ... 就完成了。
为什么不用 requirements.txt？直接一条命令更直观，下面也会介绍文件方式。

每个包是干什么的？（以后忘了回来看）

包名角色一句话说明
chromadb 向量数据库 把文档的"语义指纹"存进去，搜索时找到最相关的片段
openai API 客户端 调用 LLM 的通用 SDK——DeepSeek 的接口格式跟 OpenAI 一样，所以也用这个包
tiktoken Token 计数 算一段文字占多少 token，分块时确保不超出模型上限
sentence-transformers 本地 Embedding 在本地运行 BGE-M3 模型把文字转成向量，免费、不消耗 API
markdown-it-py Markdown 解析 解析 .md 文件，保留标题层级结构
pdfplumber PDF 解析 提取 PDF 里的文字和表格，中文支持好
python-docx Word 解析 读取 .docx 的段落和标题样式
beautifulsoup4 HTML 解析 清洗网页标签，提取纯文本内容
lxml HTML 引擎 BeautifulSoup 的底层解析加速器
python-dotenv 配置管理 从 .env 文件读 API Key，不会把密钥写死在代码里
streamlit Web 界面 Phase 4 用，几行代码搭一个 Chat 对话网页

备选安装方式：用 requirements.txt

如果你更喜欢用文件管理依赖（推荐长期维护用），项目里已经准备好了 requirements.txt：

pip install -r requirements.txt

效果跟上面那条长命令完全一样。

✅ 第 3 步完成。以后每次打开终端只用做 3.1（激活），不需要重新安装。

第 4 步：配置 API Key

4.1 创建 .env 文件

项目里已经有一个 .env.example 模板文件。把它复制一份，命名为 .env：

copy .env.example .env

.env.example 可以提交到 Git（不包含真实 Key），但 .env 不能提交——所以 .gitignore 里已经忽略了它。

4.2 填入 DeepSeek API Key（主力）

打开刚才生成的 .env 文件，找到这一行，把后面的占位符换成你的真实 Key：

DEEPSEEK_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx  ← 换成你自己的

API Key 从哪获取？

平台获取地址费用说明
DeepSeek platform.deepseek.com/api_keys 极便宜，百万 token 约 ¥1，中文效果很好，LLM 生成的主力
OpenAI platform.openai.com/api-keys 备选，DeepSeek 挂了临时切过来用
注册 DeepSeek：打开 platform.deepseek.com → 注册账号 → 顶部菜单"API Keys"→ 创建新 Key → 复制保存。
新用户通常有免费额度，够开发测试用很久。

4.3 本项目用哪些 API？

用途默认方案需要 Key？为什么选它
🧠 LLM 生成回答 DeepSeek (deepseek-chat) ✅ 需要 DeepSeek Key 便宜、中文流畅、OpenAI 兼容格式
🔢 文本转向量 本地 BGE-M3 ❌ 不需要 免费、离线可用、中文效果好、首次运行自动下载模型

💡 为什么 Embedding 用本地模型而不是 API？因为 Embedding 是纯计算任务，本地跑 BGE-M3 不花钱、不用联网，而且这个模型中文效果很好。当然如果你想用 OpenAI 的 embedding，在 .env 里把 EMBEDDING_PROVIDER 改成 openai 就行。

✅ 第 4 步完成。最少只需要一个 DeepSeek API Key，项目就能跑起来了。

第 5 步：验证一切正常

在终端里（确保已激活 rag-env）依次执行这些检查命令：

# 1. 确认在虚拟环境里
python -c "import sys; print(sys.prefix)"
# 输出应该包含 rag-env 路径 → 说明在正确环境里

# 2. 逐包检查导入
python -c "import chromadb;          print('✅ chromadb           ', chromadb.__version__)"
python -c "import openai;            print('✅ openai             ', openai.__version__)"
python -c "import tiktoken;          print('✅ tiktoken             OK')"
python -c "import sentence_transformers; print('✅ sentence-transformers', sentence_transformers.__version__)"
python -c "import markdown_it;       print('✅ markdown-it-py       OK')"
python -c "import pdfplumber;        print('✅ pdfplumber           OK')"
python -c "import docx;              print('✅ python-docx          OK')"
python -c "import bs4;               print('✅ beautifulsoup4       OK')"
python -c "import dotenv;            print('✅ python-dotenv        OK')"
python -c "import streamlit;         print('✅ streamlit            OK')"

# 3. 检查 .env 文件能不能正常读取
python -c "from dotenv import load_dotenv; import os; load_dotenv(); print('DEEPSEEK_KEY:', os.getenv('DEEPSEEK_API_KEY')[:8]+'...' if os.getenv('DEEPSEEK_API_KEY') else '❌ 未配置')"
如果全部输出 ✅，环境搭建就完成了！可以进入 Phase 1，开始写核心代码。
