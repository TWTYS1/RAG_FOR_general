T2.2 PDF 解析

项目说明
目的验证 PDF 按页提取文本
前置条件docs/ebooks/ 下有至少一个 .pdf 文件（可手动放入）
步骤 
python -c "
from src.parsers.pdf_parser import PDFParser
from pathlib import Path
import glob
pdfs = list(Path('docs/ebooks').glob('*.pdf'))
if pdfs:
    docs = PDFParser().parse(pdfs[0])
    print(f'pages: {len(docs)}')
    for d in docs[:3]:
        print(f'page {d.metadata[\"page\"]}: {d.text[:80]}...')
else:
    print('no PDF found, skip')
"
预期结果 每页一个 Document，metadata 含 page 字段，text 非空
